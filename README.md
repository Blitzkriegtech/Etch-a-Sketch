# Etch-a-Sketch (A TOP project)

Description:
A typical sketching app with default grid size of 16 by 16 on a 600px width sketch area.

Specifications:
1. Grid toggle - for grid visibility.
2. Clear toggle - for clearing/resetting the sketch pad.
3. Color(random) toggle - for etching random colors.
4. Erase toggle - for erasing/resetting of specific grid.
5. Shade toggle - for applying shade to colors from light - dark.
6. Color picker - for etching specific color which user can choose from.
7. Grid size - allows user to choose grid size with a range of 1 - 100.
